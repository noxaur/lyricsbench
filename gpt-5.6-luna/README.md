# Umbra — rebuilt

A self-contained React Router/Vite rebuild of the Umbra lyrics player.

```bash
npm install
npm run dev
```

The player deliberately uses a local timed-lyrics session so its core behavior is dependable without external YouTube, Spotify, or lyrics-provider credentials. Search supports titles and pasted links; the player supports click-to-seek, playback simulation, lyric follow/manual modes, timing nudges, bilingual display, keyboard controls, and persisted recent sessions/theme preference.

```bash
npm run build
```
